# Menezes Design OS integration

The source of truth for owned tokens, UI, motion, blocks, catalog, source registry and design-intelligence links is `menezesx2k26-byte/menezes-design-os` (private).

Agent responsibility is unchanged:
1. `frontend-director` retains decision authority and owns implementation quality.
2. `reuse-first-router` discovers whether existing project primitives or the Design OS already solve a problem.
3. `frontend-director` chooses specialist skill(s) such as UI/UX Pro Max, Taste, Emil Kowalski and Impeccable on demand.
4. No wholesale installation, third-party library copying, forced branding, production rollout, GitHub visibility change, API/security boundary change, or credentials in source.
5. The Design OS is consumed through a versioned, authenticated channel after a compatibility pilot; the source registry is not an anonymous private GitHub CLI registry.
6. Preserve the consumer repository's own definition of done and test/rollback evidence.

This integration is guidance only; product work remains in each product's repository.
